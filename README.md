# game-server-catalog

The public catalog of games supported by [GameHostCloud](https://gamehostcloud.com) —
59 titles across survival, FPS, simulation, racing and community platforms.

`games.json` — one object per title:

```json
{
  "id": "minecraft",
  "name": "Minecraft",
  "category": "game-server",
  "family": "minecraft-java",
  "steamAppId": null,
  "defaultPort": 25565
}
```

Categories: `game-server` · `mod-service` · `non-standard-service` · `bot-hosting`.

Every `id` maps to a public landing page at `https://gamehostcloud.com/games/<id>`.
